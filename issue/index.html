One-time setup: connect to GitHub

This lets the tool publish certificates to verify.u-tech.in by itself. You do this once on this computer.

  1. Open github.com/settings/personal-access-tokens/new (signed in to GitHub).
  2. Token name: U-TECH certificates · Expiration: choose Custom → 1 year (or No expiration).
  3. Repository access: Only select repositories → choose verify.
  4. Permissions → Repository permissions → Contents: set to Read and write.
  5. Click Generate token, copy it, and paste it below.

The token is stored only in this browser on this computer. It can only change the verify repository.
